# 🐛 Code Complexity Analyzer

A Python-based tool that analyzes source code and provides basic
estimates of time complexity, space complexity, loops, conditions,
functions, and code quality.

## Features

- Count lines of code
- Detect loops
- Detect nested loops
- Detect conditions
- Detect functions
- Estimate time complexity
- Estimate space complexity
- Generate a code quality score
- Explain the detected complexity

## Technologies

- Python
- Streamlit
- Regular Expressions
- Git
- GitHub
